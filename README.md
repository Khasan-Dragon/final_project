## Функциональность

- Проект реализует веб-сервер для управления задачами с поддержкой повторяющихся событий, API и фронтенда.

## Структура проекта

```
final_project/
├── main.go                # Главный файл приложения
├── scheduler.db           # Файл базы данных SQLite (создается автоматически)
├── pkg/                   # Пакеты
 ├─ api/                   # API-обработчики
 ├─ db/                    # Работа с БД
 ├─ nextdate/              # Логика повторений
 └─ server/                # Запуск сервера
tests/                     # Тесты
web/                       # Фронтенд            

```

## Зависимости
- Go 1.23+
- SQLite (через modernc.org/sqlite)
- testify (для тестов)
- `modernc.org/sqlite` - драйвер SQLite без CGO
- Стандартная библиотека Go для HTTP сервера

## База данных

Таблица `scheduler` с полями: `id`, `date` (YYYYMMDD), `title`, `comment`, `repeat` (правила повторений).

```

## Запуск сервера

1. Убедитесь, что у вас установлен Go (версия 1.23 или выше)
2. Перейдите в директорию проекта:
   ```bash
   cd final_project
   ```
3. Загрузите зависимости:
   ```bash
   go mod tidy
   ```
4. Запустите сервер:
   ```bash
   go run main.go
   ```

## Доступные URL

После запуска сервера вы можете получить доступ к следующим файлам:

- **Главная страница**: http://localhost:7540/
- **CSS файлы**: 
  - http://localhost:7540/css/style.css
  - http://localhost:7540/css/theme.css
- **JavaScript файлы**:
  - http://localhost:7540/js/scripts.min.js
  - http://localhost:7540/js/axios.min.js
- **Иконка**: http://localhost:7540/favicon.ico
- **Страница входа**: http://localhost:7540/login.html

## Тестирование

1. Убедитесь, что сервер запущен на порту 7540.
2. Запустите тесты:
   ```bash
   go test ./tests/...
   ```

## Остановка сервера

Для остановки сервера нажмите `Ctrl+C` в терминале, где запущен сервер.
